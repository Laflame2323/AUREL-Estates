# AUREL Estates

A bespoke luxury real-estate website concept built with React, TypeScript, and custom CSS.

## Design
- Deep navy, warm ivory, stone and champagne-gold palette.
- Full-bleed architectural hero photography.
- Responsive editorial layout, property collection filters, property detail modal, and enquiry form interaction.
- Reduced-motion support.

## Run locally
This project was originally authored in the Higgsfield website workspace. The `app/` folder contains its application source and workspace dependencies.

```bash
cd app
bun install
bun run dev
```

## Portfolio note
AUREL Estates and the displayed property listings are fictional portfolio concepts. The enquiry form is a front-end demonstration and is not connected to a real inbox or CRM. Replace demo copy, images, and listing details before using this as a live estate agency website.
